## Transcription decision log

- **Derived nodes**: branches in the design that hang off a main node ("failure path / secret passage / detour", etc.) are placed under the main number plus a lowercase suffix (`N0-3a/b`, `N1-2b`, `N2U-1b`, `N2G-2b/2c`, `N2L-1b`, `R4-r`, `N4-1b`). The node budget counts logical nodes by main number; derived nodes don't consume budget.
- **Ending nodes**: the design's N4-3 (ending cutscene) and N4-4 (epilogue settlement) are not separate nodes; they are merged into E1–E4 with `type: "ending"` — an ending node's inherent duties are cutscene + settlement + NG+ Board writes.
- **Entry to N1-7**: the Ink-Rain Night Raid is a time edge at the event layer (`ink_rain_raid` in `events.json`, triggered when the clock reaches 2); on the graph, the three contact nodes (N1-4/5/6) converge into N1-7 as in the campaign book.
- **R2 fragment**: the design's "R2 hidden ×1" sits on the success path of the Soothe check (success = you notice the details of the child's hiding place).
- **Text**: the first version embedded Chinese summaries; `lore.json` reserved a `text_ref` slot for text extraction.
- **Long text externalised (wired in during the writing phase, tech/02 §1.1 v0.7)**: 41 non-ending nodes gained `text_ref` (`texts/zh-CN.json#node.<id>.text`); the full E1–E4 ending cutscene text goes through the endings table `text_ref` (`#ending.<id>.text`, with `content` keeping a one-line summary as fallback); the 7 lore body keys were normalised to `#lore.<id>`. `texts/zh-CN.json` has 52 keys in total (41 nodes + 4 endings + 7 lore). SL-0/SL-1 were polished from the prototype/data.js text; SL-2~SL-4 / rooms / endings / Compendium are newly written. The file only carries text and introduces no undeclared flags or effects.
- **Flag readers completed (code review M3)**: the five readers declared in campaign book §5 were never placed (those choices had no visible consequence). Each now has one paragraph of "echo" via `text_variants` in `append` mode: seeing_is_believing → R2, insider → N3-1, page_tearer → N4-1 and E2, blank_memory → E1, could_not_save → E4 (the endings table gains text_variants). R2's "dialogue bonus" is placed narratively (the check numbers are unchanged); presentation-surface readers such as the History Scroll, bond events and Compendium unlocks stay V4 WARN for manual review.
- **Alignment placement completed (TP1 transcription)**: campaign book §9 ending conditions require Inkbound/Blankward past the midline, but the first node graph had no alignment write points. Following §9's intent: the Scriptorium chain (both choice edges at N2S-3) +10 each (Inkbound); the Uninked chain (both choice edges at N2U-2) -10 each (Blankward); the Salvage Guild and lone-wolf chains leave alignment alone (corresponding to the E4 path).
- **Tide Chart placement completed (TP1 transcription)**: campaign book §8 lists "N1-1 shop" as a source but the first graph had nowhere for it. Added a "Buy the Half-Page Tide Chart" choice edge at the N1-1 hub (give_item, placeholder price). The second source "N1-2 hidden pickup" is left for when exploration encounters are fleshed out (open item; TP1 acceptance ruling 4 stands).
- **Lone-wolf entrance completed (TP1 acceptance ruling 1)**: the original graph forced the player through one faction contact node (reputation +1), so the N1-8 lone-wolf gate (all three ≤ 0) could never be met. Added a "Decline every invitation" choice edge at N1-3 going straight to N1-8 (no effects, reputation stays 0); the SL-1 diagram in campaign book §4 was updated to match.
- **Bond placement completed (TP1 acceptance ruling 2)**: E3 needs any Bond ≥ 60 (campaign book §9), but the first version had no bond writes. Placement: post-battle edge at N1-7 +10, both edges at N2S-3 +15 each, on_enter of N2U-3/N2G-3 +15 each, R2 Soothe success +20; the companion id is temporarily `kelan` (placeholder until the TP companion system is finalised). The in-graph cap for one playthrough is 45; E3's threshold of 60 is reached via NG+ carry-over (what you earned in the graph last time).
- **Encounter late registration (TP1 acceptance ruling 3)**: N2G-2c (detour, maze/inherit/medium/4) and R1 (pickup-check room, maze/forced_time/easy/2) were added to encounters.json, with encounter links added on the node side; total encounters 14 → 16.
- **Battle stats into tables (first step of the M2 path)**: three new tables — characters/skills/enemies — with values transcribed key-by-key from the tech prototype TP2 bootstrap script (consistent with doc 11; a transcription, not a re-creation). The bootstrap layer (main.gd) now assembles battle definitions from pack data; byte-for-byte identical event streams for the same seed and commands as the old hard-coded version serve as hard proof of "no re-creation". HP/AC formulas take the simple forms that reproduce current values (e.g. `10 + 2*might` = 14), with the rule-pack evaluator (tech/04 §2) landed alongside.
- **Field-extension registration (M2)**: `party` / `enemies` / `party_advantage` / `loot` / `xp` in encounters.json and `basic_attack` in characters.json are all optional extension fields, registered in tech/02 §6 and tech/04 §2 (§11: all new fields are optional). `party_advantage` is the content-pack declaration of 11 §3.1 "witnessed a revocation → whole party has advantage on the first round".
- **Stats finalised (story/03 v1.1)**: final enemies.json values follow the simulation calibration in `../03-balance-and-boss-design.md` §1 (winrate, 200 runs per encounter, all within bands); all "stats pending" markers removed. The Page Warden / Inktide Avatar carry `behavior` turn scripts (§2 schema: every_n_rounds / when_hp_below+once), and the boss skills seal_shock / Rewrite the Rules / tide_sweep / call_imps are finalised per §3.1/§3.2 (summons respect the ≤8 on-screen limit).
- **Ink Shield value (M2 ruling)**: per 11 §3.1 and the prototype's hard-coded behavior, the effect is only "attackers have disadvantage while it lasts" — **no AC+2**. The "AC+2" in the task description conflicts with the doc and was not placed; it can be added as one line of data after a ruling (runtime statuses already support `ac_bonus`).
- **heal_potion use block (M2 ruling)**: uses flat keys `{timing, heal, consume}` (matching the runtime); the nested `effect` shape in the tech/04 §4 example will be unified once the §5 effect system runtime lands (the spec has a placement note).
- **Price placeholders (M2)**: the Half-Page Tide Chart in the N1-1 shop has a placeholder price of 15, stored in the optional `price` field of `items.json` and in the edge label; heal_potion is placed as ×2 brought in from the Prologue (campaign book §4), with the N1-1 shop reference recorded in `source`; the Supply Potion is also on sale for 15 gold (M2 node-flow acceptance ruling B, overturning this line's earlier "no new purchase edge" note).
- **Supply Potion on sale (M2 node-flow acceptance ruling B)**: campaign book §8 item table now registers "Supply Potion | numeric (consumable) | N1-1 shop (15 gold placeholder) / brought in from Prologue ×2"; `items.json` heal_potion gains `price: 15`; the N1-1 shop list gains a purchase edge (same structure as the Tide Chart: give_item + go to the scene).
- **Other battle encounters' enemies not finalised (M2 gap)**: only N1-7 registers `party`/`enemies` instances; enemy line-ups for R3/R5/N4-1 and other battles await content finalisation, and V11 only validates the closure of references that are declared.
- **Act III / Finale line-ups registered (Act III integration; placeholder stats pending finalisation)**: R3 Ink Fiend Nest (Fiend + Imp×2), R4-r corridor right path first battle (Swarm×2 + Imp), R4-r2 second battle (Fiend + Swarm), R5 Page Warden (the Scriptorium's automatic scribing golem, adapted from the arena's Page Warden elite: Seal Shock save DC12/half mounted on the entry, 11 §5.1), N4-1 Inktide Avatar (final boss: Inktide Sweep AoE + Imp×2; landscape recommended, 6 on screen). enemies.json gains page_warden / tide_avatar; V11 line-up WARNs for R4-r2 etc. are cleared.
- **R4-r split into two battles (Act III transcription)**: the campaign book's Act III "right path is two battles" is placed as the derived-node chain `R4-r → R4-r2 → R5` (main number R4; derived nodes don't consume budget, same rule as V6); no rest between battles, HP persists across encounters per 11 §7.1.
- **N4-1 battle-avoidance gate (Finale integration ruling)**: both the campaign book and items.json say "persuade the guards to stand down **before** N4-1 [I/R]", but the first graph made N4-1 both the battle node and the carrier of the avoidance edge (the edge only settled after the battle, so avoidance never appeared). Ruling: N4-1 becomes a `scene` gate node (no encounter attached), with an item edge (Signet + Scriptorium reputation ≥ 1) going straight to N4-2 without a battle; fallback → N4-1b assault battle (encounter N4-1 unchanged). The boss battle mechanics design remains an open item in campaign book §11.
- **Mercy lowers difficulty (Finale integration)**: the N4-1 encounter declares `enemy_weaken: { "flag": "mercy_shown", "attack_mod": -2 }` (registered in tech/02 §6 v0.4) — a flag-driven modifier symmetric with party_advantage. Campaign book §5 "page_tearer → tax collector absent" is a presentation difference and is not placed in this slice.
- **Ending flags and epilogue writes (Finale integration)**: E1–E4 on_enter write `ending_e1`~`ending_e4` respectively; E3 additionally writes `unlock_scribe_identity` (placeholder for unlocking the "Penbearer" origin), and E4 writes `ngplus_memory_view` (placeholder for the NG+ "Remembrance" perspective) — NG+ carry-over balance was still an open item in campaign book §11, so placeholder flags came first. The settle point of the `last_page` event moved from N4-1 to N4-2 (both the avoidance and assault paths write `campaign01_cleared` before the ending, aligned with "epilogue settlement").
- **Act III mode lock (Finale integration)**: manifest.presentation gains `forced_except: { "SL-3": ["N3-7"] }` (registered in tech/02 §2.1 v0.4) — the SL-3 act is forced portrait, and from N3-7 the Blank Plaza the player's chosen form returns (campaign book Act III "landscape unlocks from here").
- **R1/R2 Compendium placement aligned (Act III integration)**: `revoked_registry_01` (the faded dwelling's house plate) moved to R1 on_enter, `revoked_registry_02` (the empty classroom's roll) stays at R2 on_enter, matching lore.json sources one-to-one (previously both were at R2; the idempotent set-union in the `revoked_zone` event settle is unchanged).
- **Gold placeholder confirmed (M2 audit X1 ruling)**: `campaign01.gold` is a counter-type flag in the pack namespace — covered by the currency clause in 07 §2 (added in v1.7), so an in-pack counter is compliant and the "pending doc ruling" status is withdrawn. Starting gold `GOLD_START := 30` is a confirmed placeholder (the campaign book doesn't define starting gold; it will be revised with one line of data when finalised).
